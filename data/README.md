# `data/` — large input files (NOT committed)

Put here (or anywhere, and point `population.path` to it) the MBHcat HDF5
files. Files in this directory are ignored by git (see `.gitignore`), apart
from this README.

Small reference tables that the code needs (e.g. the Broggi+22 Fig. 6 curve)
are *committed* inside the package instead, in `emricat/data/`.
